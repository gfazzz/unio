# RFC языка Unio

Английская версия (основная): [docs/rfcs/README.md](../../rfcs/README.md).

RFC (request for comments) — способ изменить синтаксис, семантику, набор ключевых слов или нормативное требование после этапа 1 [плана](../plan.md). До этого изменения вносятся прямо в концепцию, ТЗ и `spec/` с пометкой «Изменения относительно» в начале изменённого документа.

## Порядок

1. Скопировать [0000-template.md](0000-template.md) в `NNNN-short-title.md` со следующим свободным номером.
2. Открыть pull request со статусом `proposed`. Обсуждение идёт в pull request.
3. Ведущий по языку принимает или отклоняет RFC. Принятый RFC получает статус `accepted`; отклонённый остаётся в репозитории со статусом `rejected` и причиной.
4. Тот же или следующий pull request обновляет `docs/concept.md`, `docs/requirements.md`, `spec/grammar.ebnf`, корпус в `spec/tests/` и русскую локализацию. RFC получает статус `implemented`, когда компилятор его поддерживает.

## Правила

- RFC, добавляющий ключевое слово или конструкцию, в отдельном разделе отвечает, почему существующие конструкции не могут выразить изменение.
- Несовместимое изменение поставляется с автоматической миграцией в `unio fmt --migrate` или с диагностикой, несущей исправление (требование Н-9).
- Изменение грамматики сопровождается корректными и некорректными файлами корпуса, которые проходят `spec/check_grammar.py --corpus`.
