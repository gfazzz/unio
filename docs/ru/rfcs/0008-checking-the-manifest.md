# RFC 0008: `unio check` проверяет манифест (E0088)

- Статус: accepted (решение руководителя проекта от 2026-11-12; реализовано в `compiler/unio/src/package/manifest.rs`, см. «Проверка»)
- Автор: проект Unio при участии Claude
- Дата: 2026-11-12
- Затрагивает: ТЗ (И-6) / семантику (docs/ru/semantics.md, 8.6) / диагностику (новый код E0088) / инструменты
- Английская версия (основная): [0008-checking-the-manifest.md](../../rfcs/0008-checking-the-manifest.md)

## Кратко

`unio check` проверяет манифест `unio.toml` каждого проверяемого пакета целиком, по тем же правилам, по которым его читают `unio run`, `unio test` и команды пакетов (И-6), и сообщает о каждой ошибке одной диагностикой E0088 на её строке манифеста. До сих пор ошибку манифеста находил только запуск — с кодом 103 и без строки.

## Мотивация

Испытание модели по Н-10 ([bench/results/control_trial-2026-11-12.md](../../../bench/results/control_trial-2026-11-12.md)) показало, что `unio check` принимал `files.read = true`, хотя это не список областей; `unio run` и `unio test` его отклоняли. Пять ответов первой попытки не прошли именно так: агент видел чистую проверку, и исправлять ему было нечего. Unio обещает, что `unio check` находит ошибки до запуска (К-2) и даёт машиночитаемую диагностику с местом и исправлением (К-8); манифест — часть пакета, поэтому его ошибки относятся к проверке.

## Решение

1. `unio check` читает манифест каждого пакета, о котором сообщает (не стандартной библиотеки и не зависимости: их манифест проверен при установке), и проверяет:
   - `[package]`: `name` (строчные буквы, цифры, `-` и `_`, начинается с буквы), `version` (семантическая версия), `unsafe_modules` (список имён модулей);
   - `[permissions]`: `files.read` и `files.write` — списки путей с подстановками `$HOME`, `$CWD` и `$TEMP`, где `*` допустима только в окончании `/**`, по тому же правилу, что в песочнице; `env` — список имён переменных; `process` — список программ; `network = false`;
   - `[dependencies]`: каждая запись — таблица ровно с одним источником (`path`; `registry` с `package` и `version`; или `archive` с `sha384`);
   - никаких других таблиц и ключей; `[compile]` и `[limits]` принадлежат внешней политике оператора (RFC 0006), а не манифесту.
2. Каждая ошибка — одна E0088 на её строке манифеста (семантика, 2.8); у манифеста, который не читается как формат, есть только эта ошибка. В текстовом выводе место — `unio.toml:СТРОКА:СТОЛБЕЦ`, в JSON — `"file": "unio.toml"`.
3. Одна ошибка — одно сообщение: пакет с ошибкой в манифесте не получает E0085, потому что его разрешения неизвестны, а импорт зависимости с ошибочной записью не получает E0048.
4. `unio run` и `unio test` по-прежнему останавливаются с кодом 103 до запуска программы; языковой сервер показывает E0088 в `unio.toml` и, с указанием места, в каждом открытом документе пакета.
5. В требование И-6 добавляется фраза: «`unio check` проверяет манифест целиком по этим правилам и сообщает о каждой ошибке кодом E0088 на её строке». В каталоге есть E0088 с объяснением, примером и исправлением.

## Миграция

Для правильных манифестов не нужна. Манифест с ошибкой, которую раньше находил только запуск, теперь не проходит `unio check`; диагностика называет исправление.

## Альтернативы

- Не проверять манифест и оставить его `unio run`: ни агент, ни человек не получают строки и исправления — именно этот сбой показало испытание.
- Сообщать об ошибке манифеста существующим кодом (E0085 или E0048): они означают эффект без разрешения и неразрешимый импорт, сообщение вводило бы в заблуждение.
- Проверять только `[permissions]`: у других таблиц та же проблема, а читатель общий.

## Проверка

- `compiler/unio/tests/manifest.rs`: 32 ошибочных манифеста, каждый — одна E0088 на своей строке; несколько ошибок — каждая по одному разу; правильные манифесты ничего не дают; лишних E0085 и E0048 нет; текстовый вывод, JSON, русские сообщения и код выхода.
- `compiler/unio/tests/lsp.rs`: `a_mistake_of_the_manifest_is_a_diagnostic_of_the_package`.
- Контрольная программа `spec/tests/control/manifest_read_not_a_list/` (проверка A по Н-10) и тест каталога для E0088.
