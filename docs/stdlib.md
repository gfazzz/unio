# Standard library: 0.1-draft

Version 0.1-draft. Russian localization: [ru/stdlib.md](ru/stdlib.md). Basis: requirements section 5, concept sections 2–4.

The standard library is written in Unio in [stdlib/std/](../stdlib/std). The sources are the normative API: signatures, documentation comments, and implementations. Everything the language can express is implemented in Unio; only operating-system and runtime primitives are `external function` declarations, allowed only in files marked `unsafe module` (S-7, S-10). This document is an overview; `unio doc` will generate the reference from the sources (D-3).

The library contains what the reference programs and the project tools use. `spec/check_api.py` checks that `docs/examples/`, `examples/`, `tools/`, and the library itself call nothing that is not declared in it. The remaining modules of requirement S-1 (`std.collections`, `std.math`, `std.decimal`, `std.path`, `std.process`, `std.time`, `std.random`, `std.log`, `std.test`) are added in stage 5 in the same form.

## Rules common to all modules

- A function that can fail lists concrete error types (S-2); none uses `fails with Error`.
- An operation blocked by the sandbox ends with the declared error, with `kind = PermissionDenied` (SB-6). A function that reports absence instead of an error (`files.exists`, `env.get`) reports a blocked object as absent.
- Every faulting operation has a safe form (L-18): `items[i]` and `items.get(i)`, `a / b` and `a.checked_divide(b)`.
- Methods with `var self` change the value and are available only on a `var` place (L-11).
- The comment of a function that needs a manifest permission (T-6) names it: `Permission: files.read`.
- `a in b` calls `b.contains(a)`.
- Writing a file is atomic (S-9). `AtomicFile` replaces its target only on an explicit `commit()`, because `release` cannot know how its block ended:

```unio
using file = try files.open_atomic(path):
    for line in report:
        try file.write_line(line)
    try file.commit()
```
